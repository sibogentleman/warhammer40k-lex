## 从精校稿制作 EPUB

需要 Python 3.10 或更高版本，以及 `lxml`、`Pillow`。

```sh
python3 -m pip install -r requirements.txt
```

从 Release 下载 `spacing-pass1.epub`，放到仓库根目录，然后运行：

```sh
python3 epub制作/build_proofread_epub.py
```

脚本读取当前 Markdown 中的校订译文、篇名、补译与校注，沿用底本的封面和图片，生成 `战锤40K_LEX设定汇编_全书精校版.epub`。它会逐段比对正文，并核验图片一致性与压缩包完整性。重新构建会更新 EPUB 标识和制作时间，因此文件散列值会变化。

早期整理、下载及原始材料核验脚本保留了当时的本地路径，跨电脑使用时需要调整；它们不是上述重建步骤的前置要求。
